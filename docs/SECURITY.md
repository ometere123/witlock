# Security model

WITLOCK targets only stable StudioNet 61999 through the repository-local CLI 0.39.1 and `https://studio.genlayer.com/api`. The single contract freezes parties, criteria, issuer wallets, independent verifier wallets, source coordinates, retrieval metadata, deadlines, decision versions, entitlements, and audit history.

The contract rejects issuer/verifier substitution, correlated parties, duplicate publication and evidence, altered source bytes, missing evidence, malformed answers, prompt instructions embedded in source material, appeal replay, late appeals, early finalization, terminal-state replay, and unauthorized custody actions. Consensus exceptions and invalid labels fail closed to `INCONCLUSIVE`; a funded case can become payable only through its immutable basis-point recovery rule after terminal finalization, and a zero-funded case remains non-payable.

Funding and settlement have separate trust boundaries. Exact incoming funding is refunded on every funded rejection, and a funded draft that reaches its acceptance deadline has a requester-only one-use refund path. Outgoing dispatch uses only frozen role-derived recipients and amounts. A dispatch is recorded before the native child transfer, and the contract never accepts a client-supplied receipt as proof that delivery occurred. Conservation is `funded = confirmed_paid + in_flight + refund_in_flight + unresolved + remaining`, with a global liability range checked against `self.balance`. Ambiguity can be marked only after the bounded observation deadline and requires a digest-bound incident.

The frontend uses injected EIP-1193 wallets only. It checks account and chain before every write, blocks wrong-network writes, distinguishes finality from execution success, rejects contradictory receipt aliases, rejects `NO_MAJORITY`, rejects leader and validator errors, accepts only the explicit post-quorum idle cancellation shape, persists pending hashes, and exposes finalized receipts through the StudioNet explorer. The route-first UI reads the chain before offering role actions.

The live proof demonstrates exact funding, funded draft recovery, immutable source authentication, delayed appeal-window enforcement, terminal finalization, split and role-bound native dispatch, and exact recipient balance deltas. Delivery remains externally observed until a reviewer checks the child message and recipient balance. Browser wrong-network blocking, injected connect, network switching, disconnect, reconnect, and a real signing attempt were observed; account switching, explicit wallet rejection, and persisted recovery after the interrupted attempt remain unverified.
