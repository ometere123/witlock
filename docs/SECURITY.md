# Security model
The deployment target is StudioNet **61999** and the repository-local CLI is **0.39.1**.
The present source does not accept GEN deposits, send GEN, or warrant economic settlement.
An evidence hash authenticates bytes, not truth, issuer authority, or ownership of a domain.
Submitter-declared source classifications never earn an automatic PASS.
The agreement contract requires the frozen issuer's actual address to authenticate a reference.
Even that issuer attestation is not independently established ground truth.
Uncertain child-transfer execution must not be treated as confirmed payment.
No backend signer, unattended funded wallets, WalletConnect, or browser Snaps.
Stop ship until GenVM Direct Mode, verified deployment source, finalized transaction evidence,
adversarial wallet flows, and payout transfer reconciliation are demonstrated on 61999.
