# Security model

WITLOCK targets only stable StudioNet 61999 through the repository-local CLI 0.39.1 and `https://studio.genlayer.com/api`. The single contract freezes parties, criteria, issuer wallets, independent verifier wallets, source coordinates, retrieval metadata, deadlines, decision versions, entitlements, and audit history.

The contract rejects issuer/verifier substitution, correlated parties, duplicate publication and evidence, altered source bytes, missing evidence, malformed answers, prompt instructions embedded in source material, appeal replay, late appeals, early finalization, and terminal-state replay. Consensus exceptions and invalid labels fail closed to `INCONCLUSIVE`; no entitlement is paid from an inconclusive ruling.

Funding and settlement have separate trust boundaries. Exact incoming funding is refunded on every funded rejection. Outgoing dispatch uses only frozen role-derived recipients and amounts. A dispatch is recorded before the native child transfer, and the contract never accepts a client-supplied receipt as proof that delivery occurred. Conservation is `funded = confirmed_paid + in_flight + unresolved + remaining`. Ambiguity can be marked only after the bounded observation deadline and requires a digest-bound incident.

The frontend uses injected EIP-1193 wallets only. It checks account and chain before every write, blocks wrong-network writes, distinguishes finality from execution success, rejects contradictory receipt aliases, rejects `NO_MAJORITY`, rejects leader and validator errors, accepts only the explicit post-quorum idle cancellation shape, persists pending hashes, and exposes finalized receipts through the StudioNet explorer. The route-first UI reads the chain before offering role actions.

The live proof demonstrates successful exact funding, explicit funded refusal refund, immutable source authentication, delayed appeal-window creation, authenticated appeal, terminal finalization, idempotent replay, and one native dispatch with an exact recipient balance delta. Delivery remains externally observed until a reviewer checks the child message and recipient balance. Browser account switching, wrong-network blocking, and signature rejection remain explicitly tracked as untested when the injected wallet surface does not expose those controls.
