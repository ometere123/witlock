# WITLOCK architecture
The requester freezes bounded criteria and an identified issuer per criterion.
The provider accepts. Either party may reference evidence, but a submitted reference
is never proof of origin. Only the nominated issuer address can attest the exact digest
from its own authenticated on-chain sender identity. Evidence remains a claim, not ground truth.
The requester seals; validator consensus then classifies the issuer assertions into
PASS, FAIL and UNKNOWN. Frozen weights drive the resulting non-economic decision.
Every payout and native value transfer remains disabled until separately verified.
